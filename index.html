السؤال 1 (مقارنة مقادير لوغاريتمية): قارن بين المقدارين $A = \ln^3\left(\frac{1}{e^2}\right)$ و $B = \ln\left[\left(\frac{1}{e^2}\right)^3\right]$:
أ) $A = B$
ب) $A > B$
ج) $A < B$ (أي $B > A$)
د) غير معرّف
• المقدار الأول: $\ln\left(\frac{1}{e^2}\right) = \ln(e^{-2}) = -2$. وبالتالي: $$A = \left[\ln\left(\frac{1}{e^2}\right)\right]^3 = (-2)^3 = -8$$ • المقدار الثاني بتطبيق خواص قوى اللوغاريتم: $$B = \ln\left[\left(\frac{1}{e^2}\right)^3\right] = 3 \ln\left(\frac{1}{e^2}\right) = 3(-2) = -6$$ بما أن $-6 > -8$، فإن $B > A$ أي $A < B$.
السؤال 2: مجموعة تعريف التابع $f(x) = \ln^2(x-3)$ هي:
أ) $]3, +\infty[$
ب) $\mathbb{R} \setminus \{3\}$
ج) $[3, +\infty[$
د) $\mathbb{R}$
التربيع على التابع كاملاً: $\ln^2(x-3) = [\ln(x-3)]^2$. يشترط فقط أن يكون ما داخل اللوغاريتم موجب تماماً: $x - 3 > 0 \implies x > 3 \implies D_f = ]3, +\infty[$.
السؤال 3: مجموعة تعريف التابع $f(x) = \ln\left((x-3)^2\right)$ هي:
أ) $]3, +\infty[$
ب) $\mathbb{R} \setminus \{3\}$
ج) $]0, +\infty[$
د) $]-\infty, 3[$
التربيع هنا داخل اللوغاريتم: يشترط $(x-3)^2 > 0$. المربع موجب دوماً لجميع الأعداد الحقيقية عدا القيمة التي تعدمه: $x - 3 \ne 0 \implies x \ne 3$. إذن: $D_f = \mathbb{R} \setminus \{3\}$.
السؤال 4: مجموعة تعريف التابع $f(x) = \ln|x-5|$ هي:
أ) $]5, +\infty[$
ب) $\mathbb{R} \setminus \{5\}$
ج) $]-\infty, 5[$
د) $[5, +\infty[$
القيمة المطلقة موجبة دوماً ما عدا عندما ينعدم ما بداخلها: $|x-5| > 0 \iff x - 5 \ne 0 \iff x \ne 5 \implies D_f = \mathbb{R} \setminus \{5\}$.
السؤال 5: مجموعة تعريف التابع $f(x) = \ln(x^2 + 3)$ هي:
أ) $\mathbb{R}$ كاملاً
ب) $]0, +\infty[$
ج) $\mathbb{R} \setminus \{-\sqrt{3}, \sqrt{3}\}$
د) $]\sqrt{3}, +\infty[$
المقدار $x^2 + 3 \ge 3 > 0$ موجب تماماً أياً كانت $x \in \mathbb{R}$، لذلك التابع معرف على كامل مجموعة الأعداد الحقيقية $\mathbb{R}$.

المطلوب تحريرياً وفق النموذج الامتحاني:
1) احسب نهايات التابع $f$ عند أطراف مجموعة تعريفه مع خطوات الحساب، واكتب معادلة كل مقارب أفقي أو شاقولي مع ذكر موقعه.
2) ادرس تغيرات التابع $f$ ونظم بها جدولاً مبيناً القيم الحدية ونوعها.
3) أثبت باستخدام مبرهنة القيمة الوسطى أن المعادلة $f(x) = 0$ تقبل حلاً وحيداً $\alpha$ ينتمي إلى المجال $]0.5, \, 0.8[$ ثم احسب قيمته الجبرية المضبوطة.
4) ارسم في معلم متجانس الخط البياني $C_f$ ومقارباته، واستنتج رسم الخط $C_g$ للتابع $g(x) = \frac{1 + x^2 + 2\ln x}{x^2}$.
1) حساب النهايات والمقاربات مع خطوات الحساب:
• عند الصفر من اليمين ($x \to 0^+$):
$$\lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} \frac{1 + 2\ln x}{x^2} = \frac{-\infty}{0^+} = -\infty$$ المستقيم $x = 0$ (محور التراتيب) مقارب شاقولي للخط $C_f$ يقع الخط عن يمينه.

• عند اللانهاية ($x \to +\infty$):
$$f(x) = \frac{1}{x^2} + 2 \cdot \frac{\ln x}{x^2} \implies \lim_{x \to +\infty} f(x) = 0 + 2(0) = 0$$ المستقيم $y = 0$ (محور الفواصل) مقارب أفقي للخط $C_f$ بجوار $+\infty$.
2) دراسة المشتق والاطراد وجدول التغيرات:
$$f'(x) = \frac{-4\ln x}{x^3} \implies f'(x) = 0 \iff x = 1, \quad f(1) = 1 \text{ (قيمة كبرى محلياً)}$$ جدول التغيرات (يسار ليمين LTR):
$x$01$+\infty$
$f'(x)$||+0-
$f(x)$|| $-\infty$$\nearrow$1$\searrow$0
3) تطبيق مبرهنة القيمة الوسطى:
• التابع مستمر ومتزايد تماماً على $]0.5, 0.8[$.
• $f(0.5) \approx -1.544 < 0$ و $f(0.8) \approx +0.865 > 0 \implies f(0.5) \cdot f(0.8) < 0$.
فبحسب مبرهنة القيمة الوسطى يوجد حل وحيد $\alpha \in ]0.5, 0.8[$ يحقق $f(\alpha) = 0$.
الحساب الجبري: $1 + 2\ln x = 0 \implies \alpha = e^{-1/2} = \frac{1}{\sqrt{e}} \approx 0.6065$.
4) استنتاج الخط $C_g$ والرسم البياني:
$$g(x) = f(x) + 1 \implies \text{انسحاب شاقولي نحو الأعلى بمقدار وحدة واحدة } \vec{v}=(0, 1)$$

مسألة 2 (100 درجة كاملة): دراسة $f(x) = \frac{2 + \ln x}{x+1}$ بالاعتماد على مبرهنة القيمة الوسطى للتابع المساعد $g$
ليكن $f(x) = \frac{2 + \ln x}{x+1}$ و $g(x) = \frac{1}{x} - 1 - \ln x$. أثبت بمبرهنة القيمة الوسطى أن $g(x) = 0$ تقبل حلاً وحيداً $\alpha = 1$ واستنتج إشارة $g$ وتغيرات $f$.
• $g'(x) = -\frac{1+x}{x^2} < 0$ فـ $g$ متناقص تماماً وصورته $\mathbb{R} \implies \alpha = 1$ حل وحيد.
• $f'(x) = \frac{g(x)}{(x+1)^2} \implies f(1) = 1$ قيمة كبرى محلياً.

مسألة 3: دراسة $f(x) = x - 2 + \ln x$ وحصر الجذر $\alpha \in ]1.5, 1.6[$
ليكن $f(x) = x - 2 + \ln x$. احسب النهايات وادرس التغيرات وأثبت وجود جذر وحيد محصور في المجال $]1.5, 1.6[$.
• $f'(x) = 1 + \frac{1}{x} > 0$ فـ $f$ متزايد تماماً وصورته $\mathbb{R}$.

مسألة 4: التابع الكسري اللوغاريتمي $f(x) = \ln\left(\frac{x+2}{x}\right)$ ومركز التناظر
ليكن $f(x) = \ln\left(\frac{x+2}{x}\right)$. عيّن مجموعة التعريف، المقاربات، واثبت أن $I(-1, 0)$ مركز تناظر.

القسم الموحد: المعادلات والمتراجحات وجمل المعادلات (حلول نموذجية تفصيلية كاملة)

شامل جبر اللوغاريتم
تمرين 1: إثبات المتراجحة اللوغاريتمية بالاعتماد على الاطراد
أثبت أنه أياً كان $x > 0$ فإن: $\ln(x+1) < x$.
بفرض $h(x) = x - \ln(x+1)$ على $[0, +\infty[$. مشتقها $h'(x) = \frac{x}{x+1} > 0$ لـ $x > 0$. التابع متزايد تماماً وبما أن $h(0) = 0$ فإن $h(x) > 0 \implies \ln(x+1) < x$.
تمرين 2: معادلة ومتراجحة الدرجة الثانية بالنسبة لـ $\ln x$
حل في $\mathbb{R}$ كلاً من: $\ln^2(x) - 3\ln(x) + 2 = 0$ و $\ln^2(x) - 3\ln(x) + 2 \le 0$.
بوضع $t = \ln x$ تصبح $t^2 - 3t + 2 = 0 \implies t \in \{1, 2\} \implies x \in \{e, e^2\}$.
المتراجحة $t \in [1, 2] \implies 1 \le \ln x \le 2 \implies x \in [e, e^2]$.
تمرين 3: المعادلة اللوغاريتمية الجذرية
حل في $\mathbb{R}$ المعادلة: $\ln\sqrt{2x-3} = \ln(6-x) - \frac{1}{2}\ln x$.
شرط الحل: $D_E = ]\frac{3}{2}, 6[$. بالضرب بـ 2 والتحويل لجداء: $x(2x-3) = (6-x)^2 \implies x^2 + 9x - 36 = 0 \implies x = 3 \in D_E$.
تمرين 4: معادلات القيمة المطلقة اللوغاريتمية الثلاث
1) $\ln|2x+3| + \ln|x-1| = 2\ln|x|$
2) $\ln|x-2| + \ln(x+4) = 3\ln(4)$
3) $\ln|x-3| + \ln|x+3| = \ln(8x)$
• 1) $|2x^2+x-3|=x^2 \implies S_1 = \{\frac{-1\pm\sqrt{13}}{2}, \frac{-1\pm\sqrt{37}}{6}\}$.
• 2) $|x-2|(x+4) = 64$ بشرط $x > -4, x \ne 2 \implies S_2 = \{8\}$.
• 3) $|x^2-9| = 8x$ بشرط $x > 0, x \ne 3 \implies S_3 = \{1, 9\}$.
تمرين 5: المتراجحة الكسرية ومتراجحات $n$
1) $\frac{\ln(2x)-1}{\ln x} \ge 0$
2) $2^n \le 100$ و $(2/3)^n > 10^{-3}$
• 1) $S = ]0, 1[ \cup [\frac{e}{2}, +\infty[$.
• 2) $n \le \frac{\ln 100}{\ln 2} \approx 6.64 \implies n \in \{0, 1, \dots, 6\}$ و $(2/3)^n > 10^{-3} \implies n \in \{0, \dots, 17\}$.
تمرين 6: جمل المعادلات اللوغاريتمية
الجملة 1: $x+y=30$ و $\ln x+\ln y=2\ln 3+\ln 25$. الجملة 2: $3\ln x+2\ln y=8$ و $2\ln x-3\ln y=1$.
• الجملة 1: $x+y=30$ و $xy=225 \implies (x, y) = (15, 15)$.
• الجملة 2: بالحل الخطي $\ln x = 2, \ln y = 1 \implies (x, y) = (e^2, e)$.
تمرين 7: كثير الحدود والمتراجحة التراكمية
$P(x) = 2x^3+5x^2+x-2$. حل $2\ln x + \ln(2x+5) \ge \ln(2-x)$.
$P(x) = (x+1)(2x-1)(x+2) \ge 0 \implies S = [\frac{1}{2}, 2[$.

الحالة III: نصف القطع المكافئ $y = x^2$ في الربع الثاني ($x < 0$) دائرة مفرغة عند النقطة المقاربة المرفوضة (0, 0)
تمرين 2: إثبات مجموع المتتالية $S_n$ بالتدريج الرياضي الكامل
لتكن المتتالية $u_n = \ln\left(\frac{n+2}{n}\right)$. أثبت بالتدريج أن: $S_n = \sum_{k=1}^n u_k = \ln\left[\frac{(n+2)(n+1)}{2}\right]$.
• الخطوة 1 ($n=1$): $S_1 = u_1 = \ln(3)$ والطرف الأيمن $\ln(\frac{3 \times 2}{2}) = \ln(3)$ محققة.
• الخطوة 2: نفرض صحة القضية لـ $n$.
• الخطوة 3 ($n+1$): $S_{n+1} = S_n + u_{n+1} = \ln[\frac{(n+2)(n+1)}{2}] + \ln[\frac{n+3}{n+1}] = \ln[\frac{(n+2)(n+3)}{2}]$. محققة بالتمام.
تمرين 3: تبسيط المقادير النيبرية والعشرية
احسب وبسّط كلاً من المقادير $A, B, C$.
• $A = 3$ | $B = -\ln 2$ | $C = 0$.
