البنك الوزاري الشامل للتابع اللوغاريتمي (بكالوريا علمي - سوريا)

الأسئلة أولاً ثم الحلول التحريرية المفصلة، جداول اطراد الفرق $h(x)$ (يسار ليمين)، الأتمتة، والمسائل الكبرى مع الرسوم البيانية المستقلة

قسم الأتمتة: تدريبات بنك الأسئلة الموضوعية (أتمتة تفاعلية)

اختيار من متعدد
السؤال 1 (مقارنة مقادير لوغاريتمية): قارن بين المقدارين $A = \ln^3\left(\frac{1}{e^2}\right)$ و $B = \ln\left[\left(\frac{1}{e^2}\right)^3\right]$:
أ) $A = B$
ب) $A > B$
ج) $A < B$ (أي $B > A$)
د) غير معرّف
• المقدار الأول: $\ln\left(\frac{1}{e^2}\right) = \ln(e^{-2}) = -2$. وبالتالي: $$A = \left[\ln\left(\frac{1}{e^2}\right)\right]^3 = (-2)^3 = -8$$ • المقدار الثاني بتطبيق خواص قوى اللوغاريتم: $$B = \ln\left[\left(\frac{1}{e^2}\right)^3\right] = 3 \ln\left(\frac{1}{e^2}\right) = 3(-2) = -6$$ بما أن $-6 > -8$، فإن $B > A$ أي $A < B$.
السؤال 2: مجموعة تعريف التابع $f(x) = \ln^2(x-3)$ هي:
أ) $]3, +\infty[$
ب) $\mathbb{R} \setminus \{3\}$
ج) $[3, +\infty[$
د) $\mathbb{R}$
التربيع على التابع كاملاً: $\ln^2(x-3) = [\ln(x-3)]^2$. يشترط فقط أن يكون ما داخل اللوغاريتم موجب تماماً: $x - 3 > 0 \implies x > 3 \implies D_f = ]3, +\infty[$.
السؤال 3: مجموعة تعريف التابع $f(x) = \ln\left((x-3)^2\right)$ هي:
أ) $]3, +\infty[$
ب) $\mathbb{R} \setminus \{3\}$
ج) $]0, +\infty[$
د) $]-\infty, 3[$
التربيع هنا داخل اللوغاريتم: يشترط $(x-3)^2 > 0$. المربع موجب دوماً لجميع الأعداد الحقيقية عدا القيمة التي تعدمه: $x - 3 \ne 0 \implies x \ne 3$. إذن: $D_f = \mathbb{R} \setminus \{3\}$.
السؤال 4: مجموعة تعريف التابع $f(x) = \ln|x-5|$ هي:
أ) $]5, +\infty[$
ب) $\mathbb{R} \setminus \{5\}$
ج) $]-\infty, 5[$
د) $[5, +\infty[$
القيمة المطلقة موجبة دوماً ما عدا عندما ينعدم ما بداخلها: $|x-5| > 0 \iff x - 5 \ne 0 \iff x \ne 5 \implies D_f = \mathbb{R} \setminus \{5\}$.
السؤال 5: مجموعة تعريف التابع $f(x) = \ln(x^2 + 3)$ هي:
أ) $\mathbb{R}$ كاملاً
ب) $]0, +\infty[$
ج) $\mathbb{R} \setminus \{-\sqrt{3}, \sqrt{3}\}$
د) $]\sqrt{3}, +\infty[$
المقدار $x^2 + 3 \ge 3 > 0$ موجب تماماً أياً كانت $x \in \mathbb{R}$، لذلك التابع معرف على كامل مجموعة الأعداد الحقيقية $\mathbb{R}$.
السؤال 6: مجموعة تعريف التابع $f(x) = \ln\left(\frac{x+2}{x}\right)$ هي:
أ) $]0, +\infty[$
ب) $]-2, 0[$
ج) $]-\infty, -2[ \cup ]0, +\infty[$
د) $\mathbb{R} \setminus \{-2, 0\}$
السؤال 7: قيمة النهاية $\lim_{x \to 0^+} \sqrt{x}\ln(x)$ تساوي:
أ) $-\infty$
ب) $0$
ج) $1$
د) $+\infty$
السؤال 8: إذا كان $f(x) = \frac{\ln x}{x^2}$، فإن القيمة الكبرى محلياً للتابع هي:
أ) $1$
ب) $\frac{1}{2e}$
ج) $\frac{1}{e}$
د) $e$

القسم الموحد: المعادلات والمتراجحات وجمل المعادلات (حلول نموذجية تفصيلية كاملة)

شامل جبر اللوغاريتم
تمرين 1: معادلة ومتراجحة من الدرجة الثانية بالنسبة لـ $\ln x$ (مع المتحول $t$ وجدول الإشارة)
المطلوب 1: حل في $\mathbb{R}$ المعادلة: $\ln^2(x) - 3\ln(x) + 2 = 0$.
المطلوب 2: حل في $\mathbb{R}$ المتراجحة: $\ln^2(x) - 3\ln(x) + 2 \le 0$.
شرط الحل والوجود (مجال التعريف):
يشترط أن يكون ما داخل التابع اللوغاريتمي موجب تماماً: $x > 0$.
إذن مجال الحل المسموح هو: $D_E = ]0, +\infty[$.
1) حل المعادلة بتغيير المتحول المساعد $t$:
نضع المتحول المساعد: $t = \ln x$.
تتحول المعادلة إلى معادلة من الدرجة الثانية بالنسبة لـ $t$: $$t^2 - 3t + 2 = 0$$ نحلها بالتحليل المباشر (أو بالمميز $\Delta = (-3)^2 - 4(1)(2) = 1$): $$(t - 1)(t - 2) = 0$$ • إما $t = 1 \implies \ln x = 1 \implies x = e^1 = e$. وبما أن $e \in D_E$ فهو مقبول.
• أو $t = 2 \implies \ln x = 2 \implies x = e^2$. وبما أن $e^2 \in D_E$ فهو مقبول.
مجموعة حلول المعادلة: $S = \{e, \, e^2\}$
2) حل المتراجحة $\ln^2(x) - 3\ln(x) + 2 \le 0$ وتنظيم جدول الإشارة للمتحول $t$:
بالمتحول المساعد $t = \ln x$ تصبح المتراجحة: $$t^2 - 3t + 2 \le 0$$ جذرا ثلاثي الحدود هما $t_1 = 1$ و $t_2 = 2$.
ندرس إشارة المقدار $P(t) = t^2 - 3t + 2$ في الجدول الآتي (من اليسار إلى اليمين):
$t$$-\infty$12$+\infty$
إشارة $t^2 - 3t + 2$+0-0+
المتراجحة تطلب المقادير السالبة أو المعدومة ($\le 0$)، فالحلول بالنسبة لـ $t$ هي: $$t \in [1, \, 2] \iff 1 \le t \le 2$$ نعيد تعويض $t = \ln x$: $$1 \le \ln x \le 2$$ بما أن التابع الأسي $\exp$ متزايد تماماً على $\mathbb{R}$، نأخذ الأس لجميع الأطراف مع الحفاظ على جهة المتراجحة: $$e^1 \le x \le e^2 \implies e \le x \le e^2$$ نقاطع الحلول مع شرط الوجود $D_E = ]0, +\infty[$: $[e, e^2] \subset ]0, +\infty[$ (محقق بالكامل).
مجموعة حلول المتراجحة: $S = [e, \, e^2]$
تمرين 2: المعادلة اللوغاريتمية الجذرية وتطبيق خواص القوى
حل في $\mathbb{R}$ المعادلة: $\ln\sqrt{2x-3} = \ln(6-x) - \frac{1}{2}\ln x$.
شرط الحل والوجود (مجال التعريف $D_E$):
• ما تحت الجذر وداخل اللوغاريتم الأول موجب تماماً: $2x - 3 > 0 \implies x > \frac{3}{2}$.
• ما داخل اللوغاريتم الثاني موجب تماماً: $6 - x > 0 \implies x < 6$.
• ما داخل اللوغاريتم الثالث موجب تماماً: $x > 0$.
نقاطع الشروط الثلاثة: $\left]\frac{3}{2}, +\infty\right[ \cap ]-\infty, 6[ \cap ]0, +\infty[ = \left]\frac{3}{2}, 6\right[$.
إذن: $D_E = \left]\frac{3}{2}, \, 6\right[$.
خطوات الحل الجبري:
نعلم أن $\ln\sqrt{2x-3} = \frac{1}{2}\ln(2x-3)$.
ننقل $-\frac{1}{2}\ln x$ إلى الطرف الأيسر: $$\frac{1}{2}\ln(2x-3) + \frac{1}{2}\ln x = \ln(6-x)$$ نضرب طرفي المعادلة بالعدد 2: $$\ln(2x-3) + \ln x = 2\ln(6-x)$$ $$\ln(x(2x-3)) = \ln\left((6-x)^2\right)$$ وبما أن اللوغاريتم تابع متباين: $$2x^2 - 3x = (6-x)^2 \implies 2x^2 - 3x = 36 - 12x + x^2$$ $$x^2 + 9x - 36 = 0 \implies (x + 12)(x - 3) = 0$$ • $x = -12 \notin D_E$ (مرفوض حتماً).
• $x = 3 \in \left]\frac{3}{2}, 6\right[$ (مقبول ومحقق).
مجموعة الحلول: $S = \{3\}$
تمرين 3: معادلات القيمة المطلقة اللوغاريتمية الثلاث مع شروط الحل الكاملة
1) $\ln|2x+3| + \ln|x-1| = 2\ln|x|$
2) $\ln|x-2| + \ln(x+4) = 3\ln(4)$
3) $\ln|x-3| + \ln|x+3| = \ln(8x)$
1) حل المعادلة: $\ln|2x+3| + \ln|x-1| = 2\ln|x|$:
شرط الحل: يجب ألا تنعدم المقادير داخل القيمة المطلقة: $2x+3 \ne 0 \implies x \ne -\frac{3}{2}$، و $x-1 \ne 0 \implies x \ne 1$، و $x \ne 0$.
إذن: $D_E = \mathbb{R} \setminus \{-\frac{3}{2}, 0, 1\}$.
تطبيق الخواص: $\ln(|(2x+3)(x-1)|) = \ln(|x|^2) = \ln(x^2) \iff |2x^2 + x - 3| = x^2$.
• الحالة الأولى: $2x^2 + x - 3 = x^2 \implies x^2 + x - 3 = 0 \implies \Delta = 13 \implies x = \frac{-1 \pm \sqrt{13}}{2} \in D_E$ (مقبولان).
• الحالة الثانية: $2x^2 + x - 3 = -x^2 \implies 3x^2 + x - 3 = 0 \implies \Delta = 37 \implies x = \frac{-1 \pm \sqrt{37}}{6} \in D_E$ (مقبولان).
$S_1 = \left\{ \frac{-1 \pm \sqrt{13}}{2}, \, \frac{-1 \pm \sqrt{37}}{6} \right\}$
2) حل المعادلة: $\ln|x-2| + \ln(x+4) = 3\ln(4)$:
شرط الحل: ما داخل اللوغاريتم الثاني موجب: $x+4 > 0 \implies x > -4$. وما داخل القيمة المطلقة غير معدوم: $x-2 \ne 0 \implies x \ne 2$.
إذن: $D_E = ]-4, 2[ \cup ]2, +\infty[$.
نعلم أن $3\ln 4 = \ln(4^3) = \ln 64$. فتصبح: $|x-2|(x+4) = 64$.
• عندما $x > 2$: $|x-2| = x-2 \implies (x-2)(x+4) = 64 \implies x^2 + 2x - 72 = 0 \implies (x-8)(x+10) = 0$.
ينتج $x = 8 \in D_E$ (مقبول)، و $x = -10 \notin D_E$ (مرفوض).
• عندما $-4 < x < 2$: $|x-2| = 2-x \implies (2-x)(x+4) = 64 \implies x^2 + 2x + 56 = 0 \implies \Delta = 4 - 224 < 0$ (مستحيلة الحل في $\mathbb{R}$).
$S_2 = \{8\}$
3) حل المعادلة: $\ln|x-3| + \ln|x+3| = \ln(8x)$:
شرط الحل: ما داخل اللوغاريتم الثالث موجب: $8x > 0 \implies x > 0$. وما داخل المطلق غير معدوم: $x \ne 3$ و $x \ne -3$. وبما أن $x > 0$ فإن الشرط يصبح: $D_E = ]0, 3[ \cup ]3, +\infty[$.
$\ln(|(x-3)(x+3)|) = \ln(8x) \iff |x^2 - 9| = 8x$.
• إذا كان $x^2 - 9 = 8x \implies x^2 - 8x - 9 = 0 \implies (x-9)(x+1) = 0 \implies x = 9 \in D_E$ (مقبول)، و $x = -1 \notin D_E$ (مرفوض لأن $x>0$).
• إذا كان $x^2 - 9 = -8x \implies x^2 + 8x - 9 = 0 \implies (x+9)(x-1) = 0 \implies x = 1 \in D_E$ (مقبول)، و $x = -9 \notin D_E$ (مرفوض).
$S_3 = \{1, \, 9\}$
تمرين 4: المتراجحة اللوغاريتمية الكسرية ومتراجحات الأس الطبيعي $n$
1) حل في $\mathbb{R}$ المتراجحة الكسرية: $\frac{\ln(2x) - 1}{\ln(x)} \ge 0$.
2) أوجد قيم $n \in \mathbb{N}$ المحققة لـ: $2^n \le 100$ و $\left(\frac{2}{3}\right)^n > 10^{-3}$.
1) حل المتراجحة الكسرية:
شرط الحل: ما داخل اللوغاريتمات موجب تماماً: $2x > 0 \implies x > 0$ و $x > 0$. والمقام لا يساوي الصفر: $\ln x \ne 0 \implies x \ne 1$.
إذن: $D = ]0, 1[ \cup ]1, +\infty[$.
• البسط ينعدم عند: $\ln(2x) = 1 \implies 2x = e \implies x = \frac{e}{2} \approx 1.359$.
• المقام ينعدم عند: $x = 1$.
ندرس الإشارة: - على $]0, 1[$: البسط سالب والمقام سالب $\implies$ الكسر موجب $(>0)$ (مقبول).
- على $]1, \frac{e}{2}[$: البسط سالب والمقام موجب $\implies$ الكسر سالب $(<0)$ (مرفوض).
- على $[\frac{e}{2}, +\infty[$: البسط موجب والمقام موجب $\implies$ الكسر موجب $(\ge 0)$ (مقبول).
$S = ]0, 1[ \cup \left[\frac{e}{2}, +\infty\right[$
2) متراجحات العدد الطبيعي $n$:
• $2^n \le 100 \implies n \ln 2 \le \ln 100 \implies n \le \frac{\ln 100}{\ln 2} \approx \frac{4.605}{0.693} \approx 6.64$. بما أن $n \in \mathbb{N}$: $$n \in \{0, 1, 2, 3, 4, 5, 6\}$$ • $\left(\frac{2}{3}\right)^n > 10^{-3} \implies n \ln\left(\frac{2}{3}\right) > -3\ln 10$. بما أن $\ln(2/3) < 0$ تنقلب المتراجحة: $$n < \frac{3\ln 10}{\ln 3 - \ln 2} \approx \frac{3 \times 2.3026}{1.0986 - 0.6931} \approx \frac{6.9078}{0.4055} \approx 17.03 \implies n \in \{0, 1, 2, \dots, 17\}$$
تمرين 5: جمل المعادلات اللوغاريتمية (طريقة الخواص وطريقة تغيير المتحول)
الجملة الأولى (تحل بالخواص وإرجاعها لمجموع وجداء): $$\begin{cases} x + y = 30 \\ \ln(x) + \ln(y) = 2\ln 3 + \ln 25 \end{cases}$$ الجملة الثانية (تحل بتغيير المتحول الخطي): $$\begin{cases} 3\ln x + 2\ln y = 8 \\ 2\ln x - 3\ln y = 1 \end{cases}$$
شرط وجود الحلول للجملتين: يجب أن يكون كلاً من المجهولين موجبين تماماً: $x > 0$ و $y > 0$.
حل الجملة الأولى بالخواص:
نطبق خاصية تحويل الجمع إلى جداء: $\ln(x \cdot y) = \ln(3^2 \times 25) = \ln(225) \implies x \cdot y = 225$.
المجموع $S = 30$ والجداء $P = 225$. العددان هما حلا المعادلة التربيعية: $$t^2 - 30t + 225 = 0 \implies (t - 15)^2 = 0 \implies t = 15$$ إذن الحل الوحيد: $x = 15, y = 15$ (كلاهما موجب ومحقق).
حل الجملة الأولى: $(x, y) = (15, 15)$
حل الجملة الثانية بتغيير المتحول:
نضع $X = \ln x$ و $Y = \ln y$: $$3X + 2Y = 8 \quad \text{و} \quad 2X - 3Y = 1$$ نضرب الأولى بـ 3 والثانية بـ 2 ونجمع: $13X = 26 \implies X = 2$.
نعوض $X=2$: $3(2) + 2Y = 8 \implies 2Y = 2 \implies Y = 1$.
العودة للمتحولات الأصلية: $\ln x = 2 \implies x = e^2$ و $\ln y = 1 \implies y = e$.
حل الجملة الثانية: $(x, y) = (e^2, \, e)$
تمرين 6: تحليل كثير الحدود $P(x)$ وربطه بالمتراجحة اللوغاريتمية التراكمية
ليكن كثير الحدود $P(x) = 2x^3 + 5x^2 + x - 2$.
1) تحقق أن $(-1)$ جذر لـ $P(x)$ وحلل $P(x)$ إلى جداء عوامل.
2) حل في $\mathbb{R}$ المتراجحة $P(x) \ge 0$.
3) استنتج حل المتراجحة: $2\ln x + \ln(2x+5) \ge \ln(2 - x)$.
• التحقق: $P(-1) = 2(-1) + 5(1) - 1 - 2 = 0$ (محقق).
• القسمة الإقليدية تعطي: $P(x) = (x+1)(2x^2 + 3x - 2) = (x+1)(2x-1)(x+2)$.
• حلول المتراجحة الجبرية $P(x) \ge 0$: $S_1 = [-2, -1] \cup [\frac{1}{2}, +\infty[$.
• شرط حل المتراجحة اللوغاريتمية: $x > 0$ و $2x+5 > 0$ و $2-x > 0 \implies D = ]0, 2[$.
• التحويل: $\ln(x^2(2x+5)) \ge \ln(2-x) \iff 2x^3 + 5x^2 + x - 2 \ge 0 \iff P(x) \ge 0$.
نقاطع مع شرط التعريف: $S = S_1 \cap ]0, 2[ = \left[\frac{1}{2}, 2\right[$.
مجموعة الحلول: $S = \left[\frac{1}{2}, 2\right[$

تمرين 1: التابع المجزأ $f(x) = \frac{x}{x - \ln x}$ عند الصفر
ليكن $f(x) = \frac{x}{x - \ln x}$ لـ $x > 0$ و $f(0) = 0$.

• $\lim_{x \to 0^+} \frac{x}{x - \ln x} = 0 = f(0)$ فـ $f$ مستمر عند الصفر من اليمين.

• $f(1) = 1, f'(1) = 1 \implies (T): y = x$.
• $f(1.1) \approx f(1) + 0.1 f'(1) = 1 + 0.1(1) = 1.1$.

مجموعات نقاط المستوي (رسوم بيانية مستقلة)، التبسيط، وإثبات المتتالية بالتدريج

هندسة وتحليل
تمرين 1: مجموعات نقاط المستوي $M(x, y)$ مع رسم بياني مستقل وثابت لكل حالة
عيّن وارسم طبيعة مجموعة النقاط $M(x, y)$ في الحالات التالية (كل حالة برسم مستقل وثابت):
الحالة I: $\ln(x) = \ln(y+1)$
الحالة II: $\ln(y) = -\ln(x)$
الحالة III: $2\ln(-x) = \ln(y)$
الحالة I: $\ln(x) = \ln(y+1)$
• شرط الوجود: $x > 0$ و $y+1 > 0 \implies y > -1$.
• المعادلة: $x = y + 1 \iff y = x - 1$.
• طبيعة المجموعة: نصف مستقيم من المستقيم $y = x - 1$ مع الشرط $x > 0$ (مفتوح عند النقطة $(0, -1)$ ويمتد باتجاه $x > 0$).
الحالة II: $\ln(y) = -\ln(x)$
• شرط الوجود: $x > 0$ و $y > 0$ (الربع الأول).
• المعادلة: $\ln(y) = \ln\left(\frac{1}{x}\right) \iff y = \frac{1}{x}$.
• طبيعة المجموعة: فرع القطع الزائد المتواجد تماماً في الربع الأول ($x > 0, y > 0$).
الحالة III: $2\ln(-x) = \ln(y)$
• شرط الوجود: $-x > 0 \implies x < 0$ و $y > 0$ (الربع الثاني).
• المعادلة: $\ln((-x)^2) = \ln(y) \iff \ln(x^2) = \ln(y) \iff y = x^2$.
• طبيعة المجموعة: نصف القطع المكافئ $y = x^2$ الواقع في الربع الثاني فقط حيث الفواصل سالبة تماماً ($x < 0$).
تمرين 2: إثبات مجموع المتتالية $S_n$ بالتدريج الرياضي (الاستقراء الرياضي)
لتكن المتتالية $(u_n)_{n \ge 1}$ معرفة وفق: $u_n = \ln\left(\frac{n+2}{n}\right)$.
أثبت بالتدريج (الاستقراء الرياضي) أنه أياً كان العدد الطبيعي $n \ge 1$ فإن المجموع $S_n = u_1 + u_2 + \dots + u_n$ يعطى بالعلاقة: $$S_n = \ln\left[\frac{(n+2)(n+1)}{2}\right]$$
خطوات الإثبات بالتدريج المعتمدة في الامتحان الوزاري:
نرمز للقضية المطلوب إثباتها بالرمز $E(n)$:
$$E(n): S_n = \ln\left[\frac{(n+2)(n+1)}{2}\right]$$ 1) خطوة البداية (من أجل $n = 1$):
• الطرف الأيسر هو الحد الأول: $$S_1 = u_1 = \ln\left(\frac{1+2}{1}\right) = \ln(3)$$ • الطرف الأيمن بالتعويض $n = 1$: $$\ln\left[\frac{(1+2)(1+1)}{2}\right] = \ln\left[\frac{3 \times 2}{2}\right] = \ln(3)$$ الطرفان متساويان، فالقضية $E(1)$ صحيحة.

2) فرضية التدريج:
نفرض أن القضية صحيحة من أجل عدد طبيعي كيفي $n \ge 1$، أي نفرض صحة: $$S_n = u_1 + \dots + u_n = \ln\left[\frac{(n+2)(n+1)}{2}\right]$$
3) إثبات صحة القضية من أجل $n+1$:
المطلوب إثبات صحة $E(n+1)$، أي إثبات أن: $$S_{n+1} = \ln\left[\frac{(n+3)(n+2)}{2}\right]$$ لدينا بحسب تعريف المجموع: $$S_{n+1} = S_n + u_{n+1}$$ نعوض $S_n$ من فرضية التدريج، ونعوض $u_{n+1} = \ln\left(\frac{n+3}{n+1}\right)$: $$S_{n+1} = \ln\left[\frac{(n+2)(n+1)}{2}\right] + \ln\left[\frac{n+3}{n+1}\right]$$ بتطبيق خاصية تحويل مجموع اللوغاريتمات إلى جداء: $$S_{n+1} = \ln\left[ \frac{(n+2)(n+1)}{2} \times \frac{n+3}{n+1} \right]$$ باختصار المقدار المشترك $(n+1)$ من البسط والمقام: $$S_{n+1} = \ln\left[ \frac{(n+2)(n+3)}{2} \right] = \ln\left[ \frac{(n+3)(n+2)}{2} \right]$$ وبذلك تكون القضية $E(n+1)$ محققة وصحيحة.
الاستنتاج: استناداً لمبدأ التدريج، القضية $E(n)$ صحيحة أياً كان $n \ge 1$.
