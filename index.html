البنك الوزاري الشامل للتابع اللوغاريتمي (بكالوريا علمي - سوريا)

الأسئلة أولاً ثم الحلول التحريرية، جداول اطراد الفرق $h(x)$، الأتمتة، والمسائل الكبرى

القسم الموحد: المعادلات والمتراجحات وجمل المعادلات والدرجة الثانية

شامل جبر اللوغاريتم
مسألة 1: معادلة ومتراجحة من الدرجة الثانية بالنسبة لـ $\ln x$
المطلوب 1: حل في $\mathbb{R}$ المعادلة: $$\ln^2(x) - 3\ln(x) + 2 = 0$$ المطلوب 2: حل في $\mathbb{R}$ المتراجحة: $$\ln^2(x) - 3\ln(x) + 2 \le 0$$
حل المعادلة والمتراجحة تفصيلياً:
• شرط الوجود والتعريف: $x > 0 \implies D = ]0, +\infty[$.
• تغيير المتحول المساعد: نضع $X = \ln x$.
تتحول العبارة إلى معادلة تربيعية بسيطة: $$X^2 - 3X + 2 = 0 \implies (X - 1)(X - 2) = 0$$ جذور المعادلة هي $X_1 = 1$ و $X_2 = 2$.
1) حلول المعادلة: $$\ln x = 1 \implies x = e^1 = e \in D$$ $$\ln x = 2 \implies x = e^2 \in D$$
مجموعة حلول المعادلة: $S = \{e, \, e^2\}$

2) حلول المتراجحة $X^2 - 3X + 2 \le 0$:
تكون العبارة سالبة أو معدومة داخل مجال الجذرين $[X_1, X_2]$: $$1 \le X \le 2 \iff 1 \le \ln x \le 2$$ بأخذ التابع الأسي المتزايد تماماً لجميع الأطراف: $$e^1 \le x \le e^2 \implies e \le x \le e^2$$
مجموعة حلول المتراجحة: $S = [e, \, e^2]$
مسألة 2: جمل المعادلات اللوغاريتمية (طريقة الخواص وطريقة تغيير المتحول)
الجملة الأولى (تحل بالخواص وإرجاعها لمجموع وجداء): $$\begin{cases} x + y = 30 \\ \ln(x) + \ln(y) = 2\ln 3 + \ln 25 \end{cases}$$ الجملة الثانية (تحل بتغيير المتحول الخطي): $$\begin{cases} 3\ln x + 2\ln y = 8 \\ 2\ln x - 3\ln y = 1 \end{cases}$$
حل الجملة الأولى بالخواص (المجموع والجداء):
شرط الحل: $x > 0$ و $y > 0$.
نطبق خواص اللوغاريتم على المعادلة الثانية: $$\ln(x \cdot y) = \ln(3^2 \times 25) = \ln(9 \times 25) = \ln(225) \implies x \cdot y = 225$$ لدينا المجموع $S = x + y = 30$ والجداء $P = x \cdot y = 225$.
العددان $x, y$ هما حلا المعادلة التربيعية: $$t^2 - S t + P = 0 \implies t^2 - 30t + 225 = 0 \implies (t - 15)^2 = 0 \implies t = 15$$ الجذر مضاعف، إذن: $x = 15$ و $y = 15$ (موجبان ومحققان).
حل الجملة الأولى: $(x, y) = (15, 15)$
حل الجملة الثانية بتغيير المتحول:
نضع $X = \ln x$ و $Y = \ln y$ بشرط $x > 0, y > 0$: $$\begin{cases} 3X + 2Y = 8 & \text{--- (1)} \\ 2X - 3Y = 1 & \text{--- (2)} \end{cases}$$ نضرب (1) بـ 3 و (2) بـ 2: $$\begin{cases} 9X + 6Y = 24 \\ 4X - 6Y = 2 \end{cases} \implies 13X = 26 \implies X = 2$$ نعوض $X=2$ في (1): $3(2) + 2Y = 8 \implies 2Y = 2 \implies Y = 1$.
العودة للمتحولات الأصلية: $$\ln x = 2 \implies x = e^2, \quad \ln y = 1 \implies y = e$$
حل الجملة الثانية: $(x, y) = (e^2, \, e)$
مسألة 3: معادلات القيمة المطلقة ومتراجحات الأس الطبيعي $n$ والمتراجحات الكسرية
1) حل في $\mathbb{R}$: $\ln|2x+3| + \ln|x-1| = 2\ln|x|$
2) حل في $\mathbb{R}$: $\ln|x-2| + \ln(x+4) = 3\ln(4)$
3) حل في $\mathbb{R}$: $\ln|x-3| + \ln|x+3| = \ln(8x)$
4) حل المتراجحة: $\frac{\ln(2x) - 1}{\ln(x)} \ge 0$
5) جد قيم $n \in \mathbb{N}$ التي تحقق: $2^n \le 100$ و $\left(\frac{2}{3}\right)^n > 10^{-3}$
1) حل $\ln|2x+3| + \ln|x-1| = 2\ln|x|$:
الشرط: $x \ne -\frac{3}{2}, 1, 0$.
$|(2x+3)(x-1)| = x^2 \iff |2x^2 + x - 3| = x^2$.
• إما $2x^2 + x - 3 = x^2 \implies x^2 + x - 3 = 0 \implies x = \frac{-1 \pm \sqrt{13}}{2}$.
• أو $2x^2 + x - 3 = -x^2 \implies 3x^2 + x - 3 = 0 \implies x = \frac{-1 \pm \sqrt{37}}{6}$.
$S = \left\{\frac{-1 \pm \sqrt{13}}{2}, \frac{-1 \pm \sqrt{37}}{6}\right\}$
2) حل $\ln|x-2| + \ln(x+4) = 3\ln(4) = \ln(64)$:
الشرط: $x > -4$ و $x \ne 2$.
إذا كان $x > 2$: $(x-2)(x+4) = 64 \implies x^2 + 2x - 72 = 0 \implies (x-8)(x+10) = 0 \implies x = 8$.
إذا كان $-4 < x < 2$: $(2-x)(x+4) = 64 \implies x^2 + 2x + 56 = 0$ مستحيلة لأن $\Delta < 0$.
$S = \{8\}$
3) حل $\ln|x-3| + \ln|x+3| = \ln(8x)$:
الشرط: $x > 0$ و $x \ne 3$.
$|x^2 - 9| = 8x \implies x^2 - 8x - 9 = 0 \implies x = 9$ أو $x^2 + 8x - 9 = 0 \implies x = 1$.
$S = \{1, 9\}$
4) حل المتراجحة $\frac{\ln(2x) - 1}{\ln(x)} \ge 0$:
الشرط: $x \in ]0, 1[ \cup ]1, +\infty[$.
البسط ينعدم عند $x = \frac{e}{2} \approx 1.359$ والمقام عند $x = 1$.
$S = ]0, 1[ \cup \left[\frac{e}{2}, +\infty\right[$
5) قيم $n$ الطبيعية:
• $2^n \le 100 \implies n \le \frac{\ln(100)}{\ln 2} \approx 6.64 \implies n \in \{0, 1, 2, 3, 4, 5, 6\}$.
• $\left(\frac{2}{3}\right)^n > 10^{-3} \implies n < \frac{3\ln 10}{\ln 3 - \ln 2} \approx 17.03 \implies n \in \{0, 1, 2, \dots, 17\}$.
مسألة 4: كثير الحدود والربط بالمتراجحة اللوغاريتمية
ليكن كثير الحدود $P(x) = 2x^3 + 5x^2 + x - 2$.
1) تحقق أن $(-1)$ جذر لـ $P(x)$ وحلل $P(x)$ إلى جداء عوامل.
2) حل في $\mathbb{R}$ المتراجحة $P(x) \ge 0$.
3) استنتج حل المتراجحة: $2\ln x + \ln(2x+5) \ge \ln(2 - x)$.
• $P(-1) = 0 \implies P(x) = (x+1)(2x^2 + 3x - 2) = (x+1)(2x-1)(x+2)$.
• حلول $P(x) \ge 0$: $S_1 = [-2, -1] \cup [\frac{1}{2}, +\infty[$.
• شرط المتراجحة اللوغاريتمية: $x \in ]0, 2[$.
• التحويل: $\ln[x^2(2x+5)] \ge \ln(2-x) \iff P(x) \ge 0$.
مجموعة الحلول: $S = S_1 \cap ]0, 2[ = \left[\frac{1}{2}, 2\right[$

جداول اطراد الفرق
التمرين 1 (الورقة 1): $f(x) = 2x - \frac{\ln x}{x}$ على $I = ]0, +\infty[$ ودراسة اطراد الفرق $h(x)$
ليكن $f$ التابع المعرف على $]0, +\infty[$ وفق: $f(x) = 2x - \frac{\ln x}{x}$.
المطلوب: أثبت أن المستقيم $\Delta: y = 2x$ مقارب مائل للخط $C_f$ في جوار $+\infty$، وادرس الوضع النسبي لـ $C_f$ مع $\Delta$ بتنظيم جدول لاطراد وإشارة تابع الفرق $h(x)$.
1) إثبات المقارب المائل:
نشكل تابع الفرق $h(x) = f(x) - y_{\Delta}$: $$h(x) = \left(2x - \frac{\ln x}{x}\right) - 2x = -\frac{\ln x}{x}$$ نحسب النهاية بجوار $+\infty$ بالاعتماد على نهاية التزايد المقارن الشهيرة $\lim_{x \to +\infty} \frac{\ln x}{x} = 0$: $$\lim_{x \to +\infty} h(x) = \lim_{x \to +\infty} \left(-\frac{\ln x}{x}\right) = -0 = 0$$ وبالتالي المستقيم $\Delta: y = 2x$ مقارب مائل للخط $C_f$ بجوار $+\infty$.
2) دراسة اطراد وإشارة تابع الفرق $h(x)$ وتنظيم الجدول الوزاري:
• إشارة الكسر $h(x) = -\frac{\ln x}{x}$ تتحدد بالبسط لأن المقام $x > 0$ دائماً على $]0, +\infty[$:
ينعدم الفرق عندما $-\ln x = 0 \iff \ln x = 0 \iff x = 1$.
• المشتق لتابع الفرق: $$h'(x) = -\frac{\frac{1}{x} \cdot x - \ln x \cdot 1}{x^2} = -\frac{1 - \ln x}{x^2} = \frac{\ln x - 1}{x^2}$$ ينعدم $h'(x)$ عند $\ln x = 1 \iff x = e$. وتكون القيمة الصغرى للفرق: $h(e) = -\frac{1}{e} \approx -0.368$.

ليكن $f(x) = \ln\left(\frac{x+1}{1-x}\right)$ المعرف على $]-1, 1[$.
المطلوب: أوجد معادلة المماس $(T)$ للخط $C_f$ في مبدأ الإحداثيات $O(0, 0)$، وادرس الوضع النسبي لـ $C_f$ مع المماس $(T)$ بتنظيم جدول لاطراد وإشارة تابع الفرق $h(x)$.
1) معادلة المماس $(T)$ في المبدأ $O(0, 0)$:

2) دراسة اطراد تابع الفرق $h(x) = f(x) - 2x$ وتنظيم الجدول:
نشتق تابع الفرق $h(x) = \ln\left(\frac{x+1}{1-x}\right) - 2x$: $$h'(x) = f'(x) - 2 = \frac{2}{1-x^2} - 2 = \frac{2 - 2(1-x^2)}{1-x^2} = \frac{2x^2}{1-x^2}$$ على المجال $]-1, 1[$ نجد أن $1-x^2 > 0$ والمقام موجب، والبسط $2x^2 \ge 0$ ينعدم فقط عند $x = 0$.

• على $]0, 1[$: $h(x) > 0 \implies C_f$ يقع فوق المماس $(T)$.
• عند $x = 0$: يمس الخط المماس ويخترقه (نقطة انعطاف).

1) $f(x) = \frac{1}{x(1-\ln x)}$:
$D_f = ]0, e[ \cup ]e, +\infty[$. المشتق $f'(x) = \frac{\ln x}{x^2(1-\ln x)^2}$ ينعدم عند $x = 1$. القيمة الصغرى محلياً $f(1) = 1$. المقاربات: $x=0, x=e, y=0$.

2) $f(x) = \ln\left(\frac{x}{x-2}\right)$:
$D_f = ]-\infty, 0[ \cup ]2, +\infty[$. المشتق $f'(x) = \frac{-2}{x(x-2)} < 0$ دوماً، التابع متناقص تماماً. المقاربات: $x=0, x=2, y=0$.

3) $f(x) = x\ln x$:
$D_f = ]0, +\infty[$. المشتق $f'(x) = \ln x + 1$ ينعدم عند $x = \frac{1}{e}$. القيمة الصغرى المطلقة $f(1/e) = -\frac{1}{e}$. $\lim_{x \to 0^+} f(x) = 0$ و $\lim_{x \to +\infty} f(x) = +\infty$.

4) $f(x) = \frac{\ln x}{x^2}$:
$D_f = ]0, +\infty[$. المشتق $f'(x) = \frac{1-2\ln x}{x^3}$ ينعدم عند $x = \sqrt{e}$. القيمة الكبرى $f(\sqrt{e}) = \frac{1}{2e}$. المقاربات: $x=0, y=0$.

الاستمرار وقابلية الاشتقاق والتقريب التآلفي المحلي

تفاضل وتحليل
المسألة 1 (الورقة الاختبارية): التابع المجزأ $f(x) = \frac{x}{x - \ln x}$ عند الصفر
ليكن $f$ التابع المعرف على $[0, +\infty[$ وفق: $$f(x) = \begin{cases} \frac{x}{x - \ln x} & ; x > 0 \\ 0 & ; x = 0 \end{cases}$$ 1) أثبت أن التابع $f$ مستمر عند $x = 0$.
2) ادرس قابلية اشتقاق التابع $f$ عند الصفر وفسر النتيجة هندسياً.
3) بيّن أن الخط $C_f$ يقبل مقارباً أفقياً عند $+\infty$ واكتب معادلته.
4) اكتب معادلة المماس $(T)$ في النقطة التي فاصلتها 1.
5) استعمل التقريب التآلفي لحساب $f(1.1)$.
• الاستمرار: $\lim_{x \to 0^+} \frac{x}{x - \ln x} = \frac{0}{0 - (-\infty)} = 0 = f(0)$ فـ $f$ مستمر عند الصفر من اليمين.
• الاشتقاق: $\lim_{x \to 0^+} \frac{f(x) - f(0)}{x - 0} = \lim_{x \to 0^+} \frac{1}{x - \ln x} = \frac{1}{+\infty} = 0 \implies f'_d(0) = 0$.
التفسير الهندسي: يقبل الخط نصف مماس أفقي موازٍ لمحور الفواصل في المبدأ $O(0, 0)$.
• المقارب الأفقي: $\lim_{x \to +\infty} \frac{x}{x(1 - \frac{\ln x}{x})} = \frac{1}{1-0} = 1 \implies y = 1$ مقارب أفقي بجوار $+\infty$.
• المماس عند $x = 1$: $f(1) = 1, f'(1) = 1 \implies (T): y = x$.
• التقريب التآلفي: $f(1.1) \approx f(1) + 0.1 f'(1) = 1 + 0.1(1) = 1.1$.
المسألة 2: التابع المجزأ $f(x) = x^2(1 - \ln x)$ ونصف المماس الأفقي
ليكن $f(x) = x^2(1 - \ln x)$ لـ $x > 0$ و $f(0) = 0$. ادرس استمرار واشتقاق التابع عند الصفر من اليمين وأوجد التقريب التآلفي لـ $f(1.1)$.
• $\lim_{x \to 0^+} (x^2 - x^2\ln x) = 0 - 0 = 0 = f(0)$ مستمر عند الصفر.
• $\lim_{x \to 0^+} \frac{x^2(1-\ln x)}{x} = \lim_{x \to 0^+} (x - x\ln x) = 0 - 0 = 0 \implies f'_d(0) = 0$ (نصف مماس أفقي عند المبدأ).
• $f(1) = 1, f'(1) = 1 \implies f(1.1) \approx 1 + 0.1(1) = 1.1$.

مجموعات نقاط المستوي، التبسيط النيبري والعشري، والمتتاليات

هندسة وجبر متقدم
مجموعات نقاط المستوي $M(x, y)$ (الورقة الثانية)
عيّن طبيعة مجموعة النقاط $M(x, y)$ في الحالات:
1) $\ln(x) = \ln(y+1)$
2) $\ln(y) = -\ln(x)$
3) $2\ln(-x) = \ln(y)$
• الحالة 1: $x > 0, y > -1 \implies y = x - 1$ (نصف مستقيم يبدأ من $(0, -1)$ مفتوح).
• الحالة 2: $x > 0, y > 0 \implies y = \frac{1}{x}$ (فرع قطع زائد في الربع الأول).
• الحالة 3: $x < 0, y > 0 \implies y = x^2$ (نصف قطع مكافئ في الربع الثاني).
تبسيط المقادير النيبرية والعشرية ($\ln$ و $\log$)
احسب وبسّط كلاً من المقادير:
$$A = \ln(e^2\sqrt{e}) - \ln(e^3) + \ln\left(\frac{e^4}{\sqrt{e}}\right)$$ $$B = \ln(432) - \ln(54) - \ln\left(\frac{4}{3}\right) + \ln\left(\frac{1}{12}\right)$$ $$C = \ln^3\left(\frac{1}{e}\right) + \left(\ln\frac{1}{e}\right)^2 + \log_{10}(100) - 2$$
• $A = \frac{5}{2} - 3 + \frac{7}{2} = 6 - 3 = 3$.
• $B = \ln\left(\frac{432 \times \frac{1}{12}}{54 \times \frac{4}{3}}\right) = \ln\left(\frac{36}{72}\right) = \ln\left(\frac{1}{2}\right) = -\ln 2$.
• $C = (-1)^3 + (-1)^2 + 2 - 2 = -1 + 1 + 0 = 0$.
المتتاليات والارتباط باللوغاريتم
1) لتكن $u_n = \ln(\frac{n+2}{n})$، أثبت أن $S_n = u_1 + \dots + u_n = \ln[\frac{(n+2)(n+1)}{2}]$.
2) ليكن $f(x) = \frac{1}{x} + \frac{\ln x}{x}$، أثبت أن فواصل التقاطع والمماس الأفقي تشكل متتالية هندسية أساسها $q = e$.
• المتتالية التلسكوبية: $u_k = \ln(k+2) - \ln k$. بالاختصار التلسكوبي يتبقى: $\ln(n+2) + \ln(n+1) - \ln 2 = \ln[\frac{(n+2)(n+1)}{2}]$.
• المتتالية الهندسية: تقاطع الفواصل $x_A = \frac{1}{e}$، المماس الأفقي $x_B = 1$، والنقطة التالية $x_C = e$. النسبة $q = \frac{1}{1/e} = e$.
