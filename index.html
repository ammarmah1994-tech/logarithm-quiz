السؤال 1 (ورقة الاختبار): حل المعادلات اللوغاريتمية في $\mathbb{R}$
1) حل في $\mathbb{R}$ المعادلة: $$\ln|2x+3| + \ln|x-1| = 2\ln|x|$$ 2) حل في $\mathbb{R}$ المعادلة: $$\ln|x-2| + \ln(x+4) = 3\ln(4)$$
حل المعادلة الأولى: $\ln|2x+3| + \ln|x-1| = 2\ln|x|$
• شرط الحل: يجب ألا تنعدم المقادير داخل اللوغاريتم والقيمة المطلقة:
$2x+3 \ne 0 \implies x \ne -\frac{3}{2}$، و $x-1 \ne 0 \implies x \ne 1$، و $x \ne 0$.
إذن مجال الحل: $D = \mathbb{R} \setminus \{-\frac{3}{2}, 0, 1\}$.
• تطبيق الخواص: $$\ln(|(2x+3)(x-1)|) = \ln(|x|^2) = \ln(x^2)$$ $$|(2x+3)(x-1)| = x^2 \iff |2x^2 + x - 3| = x^2$$ الحالة الأولى: $$2x^2 + x - 3 = x^2 \implies x^2 + x - 3 = 0$$ $$\Delta = 1 - 4(1)(-3) = 13 \implies x = \frac{-1 \pm \sqrt{13}}{2} \in D$$ الحالة الثانية: $$2x^2 + x - 3 = -x^2 \implies 3x^2 + x - 3 = 0$$ $$\Delta = 1 - 4(3)(-3) = 37 \implies x = \frac{-1 \pm \sqrt{37}}{6} \in D$$
مجموعة الحلول: $S = \left\{ \frac{-1 \pm \sqrt{13}}{2}, \, \frac{-1 \pm \sqrt{37}}{6} \right\}$
حل المعادلة الثانية: $\ln|x-2| + \ln(x+4) = 3\ln(4)$
• شرط الحل: $x+4 > 0 \implies x > -4$ مع $x - 2 \ne 0 \implies x \ne 2$.
إذن مجال الحل: $D = ]-4, 2[ \cup ]2, +\infty[$.
• تطبيق الخواص: $3\ln(4) = \ln(4^3) = \ln(64)$. $$\ln(|x-2|(x+4)) = \ln(64) \iff |x-2|(x+4) = 64$$ إذا كان $x > 2$: $|x-2| = x-2$: $$(x-2)(x+4) = 64 \implies x^2 + 2x - 8 = 64 \implies x^2 + 2x - 72 = 0$$ $$(x + 10)(x - 8) = 0 \implies x = 8 \in D \quad (\text{مقبول}), \quad x = -10 \notin D \quad (\text{مرفوض})$$ إذا كان $-4 < x < 2$: $|x-2| = -(x-2) = 2-x$: $$(2-x)(x+4) = 64 \implies -x^2 - 2x + 8 = 64 \implies x^2 + 2x + 56 = 0$$ $$\Delta = 4 - 4(1)(56) < 0 \quad (\text{مستحيلة الحل})$$
مجموعة الحلول: $S = \{8\}$
السؤال 2 (ورقة الاختبار): تعيين مجموعة قيم العدد الطبيعي $n$
جد مجموعة قيم العدد الطبيعي $n$ التي تحقق المتراجحة المعطاة:
1) $2^n \le 100$
2) $\left(\frac{2}{3}\right)^n > 10^{-3}$
1) حل المتراجحة $2^n \le 100$:
بأخذ اللوغاريتم للطرفين: $$\ln(2^n) \le \ln(100) \implies n \ln 2 \le \ln(100) \implies n \le \frac{\ln(100)}{\ln 2}$$ نعلم أن $\ln(100) \approx 4.605$ و $\ln 2 \approx 0.693$: $$n \le \frac{4.605}{0.693} \approx 6.64$$ وبما أن $n$ عدد طبيعي ($n \in \mathbb{N}$):
قيم $n$: $n \in \{0, 1, 2, 3, 4, 5, 6\}$
2) حل المتراجحة $\left(\frac{2}{3}\right)^n > 10^{-3}$:
بأخذ اللوغاريتم للطرفين: $$n \ln\left(\frac{2}{3}\right) > -3 \ln(10)$$ بما أن $\frac{2}{3} < 1 \implies \ln\left(\frac{2}{3}\right) < 0$، نقسم الطرفين على المقدار السالب فتنقلب جهة المتراجحة: $$n < \frac{-3 \ln(10)}{\ln(2) - \ln(3)} = \frac{3 \ln(10)}{\ln(3) - \ln(2)}$$ $$\ln(10) \approx 2.3026, \quad \ln 3 \approx 1.0986, \quad \ln 2 \approx 0.6931 \implies \ln 3 - \ln 2 \approx 0.4055$$ $$n < \frac{3 \times 2.3026}{0.4055} = \frac{6.9078}{0.4055} \approx 17.03$$
قيم $n$ الطبيعية: $n \in \{0, 1, 2, \dots, 17\}$
السؤال 3 (ورقة الاختبار): بسّط العبارات الآتية
احسب وبسّط كلاً من المقدارين:
$$A = \ln(e^2\sqrt{e}) - \ln(e^3) + \ln\left(\frac{e^4}{\sqrt{e}}\right)$$ $$B = \ln(432) - \ln(54) - \ln\left(\frac{4}{3}\right) + \ln\left(\frac{1}{12}\right)$$
تبسيط المقدار $A$:
نعلم أن $\sqrt{e} = e^{1/2}$: • $\ln(e^2\sqrt{e}) = \ln(e^{2 + 1/2}) = \ln(e^{5/2}) = \frac{5}{2}$.
• $\ln(e^3) = 3$.
• $\ln\left(\frac{e^4}{\sqrt{e}}\right) = \ln(e^{4 - 1/2}) = \ln(e^{7/2}) = \frac{7}{2}$.
$$A = \frac{5}{2} - 3 + \frac{7}{2} = \left(\frac{5}{2} + \frac{7}{2}\right) - 3 = \frac{12}{2} - 3 = 6 - 3 = 3$$
النتيجة: $A = 3$
تبسيط المقدار $B$:
نجمع اللوغاريتمات الموجبة ونطرح السالبة داخل لوغاريتم واحد بالخواص: $$B = \ln\left( \frac{432 \times \frac{1}{12}}{54 \times \frac{4}{3}} \right) = \ln\left( \frac{\frac{432}{12}}{18 \times 4} \right) = \ln\left( \frac{36}{72} \right) = \ln\left(\frac{1}{2}\right) = -\ln 2$$
النتيجة: $B = -\ln 2$
السؤال 4 (ورقة الاختبار): التابعان $f$ و $g$ المعرفان على $]0, +\infty[$
ليكن $f(x) = (x+1)\ln(x)$ و $g(x) = \frac{x\ln x + x + 1}{x}$.
المطلوب:
1) ادرس اطراد التابع $g$ ثم استنتج أن $g(x) > 0$.
2) احسب نهايات التابع $f$.
3) أثبت أنه أياً كانت $x > 0$ فإن $f'(x) = g(x)$.
4) بالاستفادة مما سبق، ادرس تغيرات التابع $f$ ونظم جدولاً بها.
5) ارسم الخط $C_f$ في معلم متجانس.
1) اطراد التابع المساعد $g(x)$:
يمكن تبسيط $g(x) = \ln x + 1 + \frac{1}{x}$.
مشتق التابع $g$: $$g'(x) = \frac{1}{x} - \frac{1}{x^2} = \frac{x-1}{x^2}$$ المشتق ينعدم عند $x = 1$. على المجال $]0, 1[$ المشتق سالب، وعلى $]1, +\infty[$ المشتق موجب.
القيمة الصغرى محلياً ومطلقاً هي: $$g(1) = \ln(1) + 1 + \frac{1}{1} = 0 + 1 + 1 = 2$$ بما أن أصغر قيمة للتابع هي $2 > 0$، فإن: $$g(x) \ge 2 > 0 \quad \forall x \in ]0, +\infty[$$
2) نهايات التابع $f$:
• $\lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} (x+1)\ln x = (0+1)(-\infty) = -\infty \implies x = 0$ مقارب شاقولي.
• $\lim_{x \to +\infty} f(x) = \lim_{x \to +\infty} (x+1)\ln x = (+\infty)(+\infty) = +\infty$.
3 + 4) المشتق وجدول التغيرات:
مشتق جداء تابعين: $$f'(x) = (1)\ln x + (x+1)\frac{1}{x} = \ln x + 1 + \frac{1}{x} = \frac{x\ln x + x + 1}{x} = g(x)$$ بما أن $g(x) > 0$ دائماً كما أثبتنا، فإن $f'(x) > 0$ دوماً، والتابع $f$ متزايد تماماً.
نقطة التقاطع مع محور الفواصل: $f(x) = 0 \iff (x+1)\ln x = 0 \iff x = 1$ لأن $x > 0$.

السؤال 5 (ورقة الاختبار): التابع المجزأ الاستمراري والمقارب والمماس
ليكن $f$ التابع المعرف على $[0, +\infty[$ وفق: $$f(x) = \begin{cases} \frac{x}{x - \ln x} & ; x > 0 \\ 0 & ; x = 0 \end{cases}$$ المطلوب:
1) أثبت أن التابع $f$ مستمر عند $x = 0$.
2) ادرس قابلية اشتقاق التابع $f$ عند الصفر وفسر النتيجة هندسياً.
3) بيّن أن الخط $C_f$ يقبل مقارباً أفقياً عند $+\infty$ واكتب معادلته.
4) اكتب معادلة المماس $(T)$ للخط $C_f$ في النقطة التي فاصلتها 1.
5) استعمل التقريب التآلفي المحلي لحساب قيمة تقريبية لـ $f(1.1)$.
6) معتمداً على ما سبق، ادرس تغيرات التابع $f$ ونظم جدولاً بها وارسم الخط $C_f$.
1) إثبات الاستمرار عند الصفر:
نحسب النهاية من اليمين: $$\lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} \frac{x}{x - \ln x} = \frac{0}{0 - (-\infty)} = \frac{0}{+\infty} = 0$$ بما أن $\lim_{x \to 0^+} f(x) = f(0) = 0$، فالتابع $f$ مستمر عند الصفر من اليمين.
2) قابلية الاشتقاق عند الصفر والتفسير الهندسي:
نهاية معدل التغير عندما $x \to 0^+$: $$\lim_{x \to 0^+} \frac{f(x) - f(0)}{x - 0} = \lim_{x \to 0^+} \frac{\frac{x}{x - \ln x}}{x} = \lim_{x \to 0^+} \frac{1}{x - \ln x} = \frac{1}{0 - (-\infty)} = 0$$ التابع اشتقاقي عند الصفر من اليمين و $f'_d(0) = 0$.
التفسير الهندسي: يقبل الخط $C_f$ في المبدأ $O(0, 0)$ نصف مماس أفقي موازٍ لمحور الفواصل بالاتجاه الموجب.
3) المقارب الأفقي عند $+\infty$:
نخرج $x$ عاملاً مشتركاً من المقام: $$f(x) = \frac{x}{x(1 - \frac{\ln x}{x})} = \frac{1}{1 - \frac{\ln x}{x}}$$ نعلم أن $\lim_{x \to +\infty} \frac{\ln x}{x} = 0$: $$\lim_{x \to +\infty} f(x) = \frac{1}{1 - 0} = 1$$ المستقيم $y = 1$ مقارب أفقي للخط $C_f$ بجوار $+\infty$.
4) معادلة المماس عند $x = 1$:
نشتق التابع على $]0, +\infty[$ كحاصل قسمة: $$f'(x) = \frac{1 \cdot (x - \ln x) - x \cdot (1 - \frac{1}{x})}{(x - \ln x)^2} = \frac{x - \ln x - x + 1}{(x - \ln x)^2} = \frac{1 - \ln x}{(x - \ln x)^2}$$ نعوض $x = 1$: $$f(1) = \frac{1}{1 - 0} = 1, \quad f'(1) = \frac{1 - 0}{(1 - 0)^2} = 1$$ معادلة المماس $(T)$: $$y - 1 = 1(x - 1) \implies y = x$$
5) التقريب التآلفي لـ $f(1.1)$:
قانون التقريب الخطي: $f(a+h) \approx f(a) + h \cdot f'(a)$ حيث $a = 1, h = 0.1$: $$f(1.1) \approx f(1) + 0.1 \cdot f'(1) = 1 + 0.1(1) = 1.1$$
6) جدول التغيرات:
المشتق $f'(x) = \frac{1 - \ln x}{(x - \ln x)^2}$ ينعدم عندما $1 - \ln x = 0 \iff x = e$.
القيمة الكبرى: $f(e) = \frac{e}{e - \ln e} = \frac{e}{e - 1} \approx 1.58$.
